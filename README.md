# BioRxiv Venture Intelligence

An automated data pipeline and exploratory analysis tool built to ingest, store, and analyze scientific preprint metadata from the live bioRxiv API.

## Project Structure
- src/ingest.py: Automated ingestion script fetching preprint metadata via API and storing it locally.
- data/: Contains raw CSV data exports (raw_biorxiv_data.csv).
- notebooks/: Jupyter notebooks dedicated to exploratory data analysis (EDA).

## Key Insights (Sample Run)
- Top Research Categories: Identified active publishing trends across fields like *Neuroscience*, *Evolutionary Biology*, and *Genomics*.
- Automated Workflow: Successfully transforms raw API responses into structured tabular data ready for analytics.

## Tech Stack
- Language: Python 3.13
- Libraries: Pandas, Requests, BeautifulSoup4
- Environment: VS Code, Jupyter Notebooks
